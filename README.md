# Money Review: member beta page

The landing page for the Money Review member beta (Go Forward Wealth Academy).

- `index.html`, `install.html` and `img/` are the whole site. No build step.
- `install.html` is the install page. When Anthropic moves its upload page, change the link in Step 2 and the address under "If something doesn't work", and update the "last checked" date. Printed guides point here, so they stay correct.
- The page is marked "noindex" so search engines skip it while it is a beta preview.
- This repository holds the page only. It contains no skill files, no statements and no personal financial data.
